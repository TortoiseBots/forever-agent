# One bot system per server until the merge

The TortoiseBots module refuses to build into a server that also builds ForeverCore playerbots. Two bot systems
driving the same characters, sessions and groups at once would fight each other, and nothing coordinates them yet.
The rule holds only until the merged bot module exists; the decision on how the two merge replaces it.
