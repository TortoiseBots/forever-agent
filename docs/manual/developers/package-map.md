The module is `github.com/pjerra/forever-agent` (Go 1.27.4). The paths below are relative to the
repository root; add the module prefix to make an import path. `cmd/` holds programs, `internal/`
holds everything else. A package's own doc comment is the authority; this table is the index.

A few conventions help while reading:

- `internal/forever/...` is the Forever (Classic 1.60.1) stack. Everything else is shared or the
  older Turtle 1.12 stack; [Architecture](architecture.md) explains the split.
- A wire package (`internal/forever/chat`, `loot`, `mail`, …) has builders and parsers only. It
  never holds session state; the session merges what a parser returns.
- The test-only helpers (`gametest`, `objtest`, `worldtest`, `navfixture`, `testfixture`) build
  packets or worlds for tests.
