* [Log a character in](log-in.md) - Log one character in with the login command, stay online, and log out cleanly.
* [login](login-reference.md) - Every login flag with its default, an example, and the login exit codes.
* [Settings file](settings-reference.md) - Every settings file key with its default, validation, and an example.
* [Write the settings file](write-settings.md) - Create the JSON settings file with the server address, accounts, folders and RPC token.
