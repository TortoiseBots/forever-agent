# The old Turtle stack

The pages here document the 1.12 Turtle stack the repository still carries: the client fight brain and its rotations, the old raid walk, the kinds of group finder, the Eluna test hooks and the old dungeon driver. Every page says at its top that the commands it describes refuse a ForeverCore server.

For the Forever manual, start at the [bundle root](../index.md). The [old bundle map](../developers/old-bundle-map.md) lists every page of the former `docs/okf` bundle, its class and where it went.

* [agent/](agent/) - The old login, session and RPC pages.
* [combat/](combat/) - The client fight brain, rotations, tactics, pet and class guides, the add-on host, Eluna and LFT.
* [dungeons/](dungeons/) - The old dungeon_run driver, its modes, party hiring, pull tests and live tuning.
* [getting-started/](getting-started/) - The old login, settings file and slot setup pages.
* [observability/](observability/) - The old capture tools and the dashboard replay.
* [raids/](raids/) - The old raid walk, suite, preflight and autopilot pages.
